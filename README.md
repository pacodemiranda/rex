# Rex

App pessoal de hábitos de atividade física, com um dinossauro como parceiro de jornada.
PWA estático (HTML, CSS e JavaScript puro, sem build) com Supabase.

- Nenhuma senha, chave `service_role` ou dado de saúde vai neste repositório. A chave publishable do `js/config.js` é pública por desenho.
- A cada alteração, suba a versão em `sw.js` (VERSION) e `js/app.js` (APP_VERSION).
